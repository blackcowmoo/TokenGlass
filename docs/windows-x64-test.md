# Windows x64 테스트 가이드

## 테스트 실행물 만들기

Windows x64 개발 PC에서 다음을 실행합니다.

```powershell
pnpm install --frozen-lockfile
pnpm build:windows-test
pnpm smoke:windows
```

`build:windows-test`는 샘플 데이터를 사용하는 테스트 모드로 Tauri 실행물을 생성합니다. 생성된 Windows 결과물을 테스트 PC로 전달합니다. 테스트 PC에는 Node.js, pnpm, Rust 또는 Codex CLI가 필요하지 않습니다.

## 수동 수락 체크리스트

- [ ] 앱을 시작하면 `TEST MODE · Sample data`가 표시되고, API 키 없이 사용량과 위젯 값이 표시된다.
- [ ] 트레이 아이콘을 한 번 클릭하면 대시보드가 표시되고, 다시 클릭하면 숨겨진다.
- [ ] 트레이 메뉴의 위젯 켜기/끄기가 동작하고, 앱을 재시작해도 마지막 위젯 표시 상태가 복원된다.
- [ ] 앱을 종료하면 프로세스와 트레이 아이콘이 사라진다.
- [ ] 실제 모드에서 올바른 관리자 API 키는 사용량을 표시하고, 잘못된 키는 키 값을 노출하지 않는 오류를 표시한다.
- [ ] 실제 모드에서 ChatGPT 로그인을 누르면 기본 브라우저가 열리고, 로그인 완료 후 새로고침할 수 있다.
- [ ] 100%와 125% 이상 화면 배율에서 대시보드와 위젯이 잘리지 않는다.
- [ ] 가능하면 보조 모니터에서 트레이 클릭 시 대시보드가 화면 밖으로 나가지 않는지 확인한다.

## 실패 보고

진단 화면에서 보고서를 복사하고, Windows 버전·화면 배율·재현 단계·스크린샷을 함께 전달합니다. API 키, OAuth 토큰, 인증 헤더, 입력 원문은 보고서나 스크린샷에 포함하지 않습니다.
