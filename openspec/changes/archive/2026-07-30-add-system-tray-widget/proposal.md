## Why

사용자가 Windows 환경에서 AI(ChatGPT 등) 사용량과 한도를 보다 직관적이고 편안하게 확인할 수 있도록, TokenGlass를 데스크탑 친화적인 시스템 트레이 애플리케이션 및 위젯 형태로 전환하고자 합니다. 이를 통해 사용자는 언제든 작업 표시줄을 통해 비용을 확인하거나 데스크탑 한구석에서 실시간 소모량을 모니터링할 수 있습니다.

## What Changes

- **메인 윈도우 표시 방식 변경**: 앱 실행 시 일반 창이 아닌 백그라운드 상태로 시작하며, 시스템 트레이를 통해서만 팝업 형태로 열립니다.
- **창 테두리 제거**: 팝업 창 형태에 맞게 OS 기본 테두리(Decorations)를 제거합니다.
- **시스템 트레이 통합**: 트레이 아이콘을 등록하고, 클릭 시 메인 대시보드 팝업창을 제어하며, 우클릭 시 컨텍스트 메뉴를 제공합니다.
- **데스크탑 위젯 추가**: 항상 위 속성을 가진 투명한 소형 위젯 창을 추가하여, 실시간 사용량을 바탕화면에 표시합니다.

## Capabilities

### New Capabilities
- `system-tray`: 시스템 트레이 아이콘 생성 및 컨텍스트 메뉴 제어, 클릭 시 메인 창의 포지셔닝 및 토글 동작
- `desktop-widget`: 투명하고 항상 위에 떠 있는 소형 위젯 윈도우 관리(켜기/끄기 설정 연동)

## Impact

- **Tauri 설정 (`tauri.conf.json`)**: 창 속성 변경 및 시스템 트레이 플러그인 설정 추가
- **Rust 백엔드 (`src-tauri/src/main.rs`, `lib.rs`)**: 윈도우 생성 로직 변경, 트레이 이벤트 핸들러 추가
- **Frontend (`src/`)**: 팝업창에 맞는 CSS 수정 및 위젯용 라우트/컴포넌트 분리
