## Purpose

바탕화면에 항상 표시되는 투명한 소형 위젯을 제공하여 사용자가 실시간으로 AI 토큰 사용량과 과금액을 모니터링할 수 있도록 합니다.

## ADDED Requirements

### Requirement: 바탕화면 위젯 창 특성
위젯 창은 데스크탑 환경에 거슬리지 않도록 항상 위, 투명 배경, 창 테두리 없음 속성을 가져야 합니다.

#### Scenario: 위젯 창 실행
- **WHEN** 사용자가 설정이나 시스템 트레이 컨텍스트 메뉴를 통해 '위젯 표시'를 켰을 때
- **THEN** 투명한 배경과 테두리가 없는 작은 텍스트/게이지 위젯이 화면 구석에 항상 위(Always on top) 상태로 나타나야 한다.

### Requirement: 드래그 앤 드롭 이동
사용자는 위젯을 클릭하고 드래그하여 원하는 위치에 배치할 수 있어야 합니다.

#### Scenario: 위젯 위치 이동
- **WHEN** 사용자가 위젯 영역을 클릭한 상태로 마우스를 이동할 때
- **THEN** 위젯 창이 마우스 포인터를 따라 부드럽게 이동해야 한다.

### Requirement: 위젯 토글 설정 저장
위젯의 활성화 여부(On/Off)는 설정에 저장되어 앱을 껐다 켜도 유지되어야 합니다.

#### Scenario: 앱 재시작 시 위젯 상태 유지
- **WHEN** 위젯이 켜진 상태에서 애플리케이션을 완전히 종료한 후 다시 실행할 때
- **THEN** 이전 설정 값에 따라 위젯이 자동으로 화면에 나타나야 한다.
