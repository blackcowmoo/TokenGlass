## MODIFIED Requirements

### Requirement: 마지막 성공 시각 표시

시스템은 OpenAI Usage/Costs API의 고정된 조회 기간에 필요한 모든 페이지를
성공적으로 조회하고 집계한 시각을 마지막 성공 시각으로 기록하고 사용자에게
표시해야 한다(MUST). 캐시를 읽거나, 페이지 조회 또는 집계에 실패한 동작은 이
시각을 변경하지 않아야 한다(MUST).

#### Scenario: 네트워크 갱신 성공

- **WHEN** OpenAI Usage API와 Costs API의 필요한 모든 페이지 조회 및 집계가 성공한다
- **THEN** 시스템은 해당 성공 시각을 결과와 함께 기록하고 메인 대시보드에 표시해야 한다

#### Scenario: 캐시 결과 표시

- **WHEN** 화면이 캐시된 사용량을 수신한다
- **THEN** 시스템은 화면이 캐시를 수신한 현재 시각이 아니라 캐시에 기록된 마지막 성공 시각을 표시해야 한다
