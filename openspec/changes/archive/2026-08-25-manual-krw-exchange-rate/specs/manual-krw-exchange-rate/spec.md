## Purpose

OpenAI API 비용의 원본 통화를 보존하면서 사용자가 지정한 환율에 따른 KRW 참고 금액을 메인 화면과 위젯에서 일관되게 확인할 수 있게 한다.

## ADDED Requirements

### Requirement: 원본 통화 비용 표시
시스템은 Costs API가 제공하는 비용 금액과 ISO 4217 통화 코드를 함께 보존하고, 비용 표시에 원본 통화를 명시해야 한다(MUST).

#### Scenario: USD 비용 표시
- **WHEN** Costs API가 USD 금액을 반환한다
- **THEN** 시스템은 USD 기호 및 소수점 형식으로 원본 비용을 표시해야 한다

### Requirement: 수동 USD-KRW 환율 설정
시스템은 사용자가 USD 1 단위당 KRW 환율을 양수 값으로 저장하고 이후 실행에서도 다시 사용할 수 있게 해야 한다(MUST). 저장된 값이 없거나 유효하지 않으면 시스템은 기본 환율 1,350 KRW/USD를 사용해야 한다(MUST).

#### Scenario: 유효한 환율 저장
- **WHEN** 사용자가 양수인 수동 환율을 저장한다
- **THEN** 시스템은 해당 값을 이후 비용 환산에 사용하고 앱을 다시 열어도 유지해야 한다

#### Scenario: 유효하지 않은 환율 입력
- **WHEN** 사용자가 0, 음수 또는 숫자가 아닌 환율을 저장하려고 한다
- **THEN** 시스템은 기존의 유효한 설정 또는 기본 환율을 유지하고 유효한 값 입력을 안내해야 한다

### Requirement: KRW 참고 환산액 표시
시스템은 원본 비용 통화가 USD일 때 저장된 수동 환율로 계산한 KRW 참고 환산액과 적용 환율을 메인 대시보드 및 데스크톱 위젯에 표시해야 한다(MUST). 시스템은 환율 API를 호출하지 않아야 한다(MUST).

#### Scenario: USD 비용의 원화 환산
- **WHEN** USD 비용과 유효한 수동 환율이 있다
- **THEN** 시스템은 USD 원본 비용과 반올림한 KRW 참고 환산액 및 적용 환율을 함께 표시해야 한다

#### Scenario: USD 이외 원본 통화
- **WHEN** 원본 비용 통화가 USD가 아니다
- **THEN** 시스템은 원본 비용만 표시하고 USD-KRW 참고 환산액은 표시하지 않아야 한다
