## 1. Windows 테스트 빌드 기반

- [x] 1.1 Windows x64 테스트 빌드용 명시적 패키지 명령과 테스트 모드 표식을 추가한다.
- [x] 1.2 테스트 빌드에 `codex-x86_64-pc-windows-msvc.exe` sidecar가 포함되는지 확인하는 검증을 추가한다.
- [x] 1.3 개발 도구가 없는 Windows x64 PC에서 실행할 수 있는 테스트 결과물 생성 절차를 문서화한다.

## 2. 테스트 모드와 진단

- [x] 2.1 외부 네트워크, API 키, OAuth 없이 대시보드와 위젯에 표시할 고정 샘플 사용량 데이터를 구현한다.
- [x] 2.2 대시보드와 위젯에 테스트 모드 및 샘플 데이터 상태를 명확하게 표시한다.
- [x] 2.3 앱 버전, Windows/아키텍처, 실행 모드, sidecar 상태, 저장소 상태 및 정제된 오류를 포함하는 진단 정보를 구현한다.
- [x] 2.4 진단 출력과 오류 처리에서 API 키, OAuth 토큰, 인증 헤더 및 원문 입력이 제외되는지 검증한다.

## 3. Windows 자동 검증

- [x] 3.1 Windows x64에서 테스트 빌드 생성, sidecar 확인, 테스트 모드 기동을 수행하는 smoke test 명령을 구현한다.
- [ ] 3.2 smoke test가 계정이나 외부 OpenAI/ChatGPT 요청 없이 성공하고, 실패 단계를 비밀 없이 보고하는지 검증한다.
- [x] 3.3 테스트 모드 데이터 및 진단 정보 정제 로직에 대한 단위 또는 통합 테스트를 추가한다.

## 4. Windows 수락 테스트

- [x] 4.1 테스트 PC용 수동 체크리스트를 작성해 시작, 트레이 표시/숨김, 위젯 표시/숨김, 설정 복원과 종료를 검증한다.
- [x] 4.2 체크리스트에 실제 API 키의 정상·오류 응답과 ChatGPT OAuth 시작 검증을 비밀 기록 없이 포함한다.
- [x] 4.3 체크리스트에 100% 및 125% 이상 DPI와 가능한 경우 다중 모니터에서 창 위치·포커스·위젯 동작 검증을 포함한다.
- [ ] 4.4 Windows x64 테스트 PC에서 smoke test와 수동 체크리스트를 실행하고 결과 및 진단 보고서를 기록한다.
