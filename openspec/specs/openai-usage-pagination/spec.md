# openai-usage-pagination Specification

## Purpose

OpenAI 조직 Usage와 Costs 데이터를 긴 기간에도 누락 없이 집계하여 사용자가
표시된 토큰과 비용을 신뢰할 수 있게 한다.

## Requirements

### Requirement: 고정 기간의 전체 페이지 집계

시스템은 하나의 조회에서 시작 시각과 종료 시각을 한 번 결정하고, 해당 기간의
Usage 및 Costs 응답을 각 API가 더 이상 페이지를 제공하지 않을 때까지 모두
집계해야 한다(MUST).

#### Scenario: Usage의 여러 일별 페이지

- **WHEN** Usage API 조회 기간에 31개를 초과하는 일별 버킷이 있고 API가 다음 페이지를 제공한다
- **THEN** 시스템은 동일한 조회 기간과 필터로 다음 페이지를 요청하여 모든 페이지의 토큰을 집계해야 한다

#### Scenario: Costs의 여러 일별 페이지

- **WHEN** Costs API 조회 기간에 한 페이지의 버킷 한도를 초과하는 결과가 있고 API가 다음 페이지를 제공한다
- **THEN** 시스템은 동일한 조회 기간과 필터로 다음 페이지를 요청하여 모든 페이지의 비용을 집계해야 한다

### Requirement: 페이지네이션 응답 무결성

시스템은 다음 페이지가 있다고 표시한 응답에 유효한 다음 페이지 커서가 없거나,
같은 커서가 반복되면 불완전한 결과를 반환해서는 안 된다(MUST).

#### Scenario: 누락된 다음 페이지 커서

- **WHEN** API 응답이 추가 페이지가 있다고 표시하지만 다음 페이지 커서가 없다
- **THEN** 시스템은 집계를 실패로 처리하고 부분적인 사용량 또는 비용을 표시하지 않아야 한다

#### Scenario: 반복된 다음 페이지 커서

- **WHEN** API가 이전에 사용한 다음 페이지 커서를 다시 반환한다
- **THEN** 시스템은 무한 요청을 하지 않고 집계를 실패로 처리해야 한다

### Requirement: 전체 기간 통화 일관성

시스템은 집계한 모든 Costs 페이지에서 원본 통화를 보존하고, 단일 조회 기간에
서로 다른 통화가 있으면 합산해서는 안 된다(MUST).

#### Scenario: 페이지 사이의 통화 불일치

- **WHEN** Costs 페이지들에서 서로 다른 원본 통화가 반환된다
- **THEN** 시스템은 비용 합계를 표시하지 않고 통화 불일치 오류를 반환해야 한다
