# system-tray Specification

## Purpose

시스템 트레이(작업 표시줄) 아이콘을 통해 TokenGlass 애플리케이션의 팝업 창을 띄우고 기본 동작을 제어할 수 있도록 합니다.

## Requirements

### Requirement: 시스템 트레이 아이콘 표시 및 동작
시스템 트레이에 애플리케이션 아이콘이 표시되어야 하며, 좌클릭과 우클릭에 대해 각기 다른 동작을 수행해야 합니다.

#### Scenario: 트레이 아이콘 좌클릭
- **WHEN** 사용자가 시스템 트레이의 앱 아이콘을 마우스 왼쪽 버튼으로 클릭할 때
- **THEN** 메인 대시보드 팝업 창이 작업 표시줄 위쪽(보통 우측 하단)에 적절한 크기로 나타나야 한다. 이미 창이 열려있다면 닫혀야 한다.

#### Scenario: 트레이 아이콘 우클릭 컨텍스트 메뉴
- **WHEN** 사용자가 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭할 때
- **THEN** 설정 열기, 위젯 토글, 종료 메뉴가 포함된 컨텍스트 메뉴가 표시되어야 한다.

### Requirement: 팝업 창 포커스 상실 시 닫기
메인 팝업 창이 열려 있을 때 화면의 다른 곳을 클릭하면 창이 자동으로 닫혀야 합니다.

#### Scenario: 다른 영역 클릭 시 팝업 닫기
- **WHEN** 메인 대시보드 팝업 창이 떠 있는 상태에서 사용자가 바탕화면이나 다른 애플리케이션을 클릭할 때
- **THEN** 팝업 창이 자동으로 화면에서 숨겨져야(Hide) 한다.
